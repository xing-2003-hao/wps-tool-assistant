# JSA 宏工具箱（兜底层）

> 不依赖加载项、不需要联网。每个文件就是一个独立的 JSA 宏，单文件即可分发给任何装了 WPS 的电脑（Windows / Mac / Linux 通用）。

## 安装方式

1. 打开 WPS 表格
2. 菜单：`工具` → `开发工具` → `JS 宏`（或 `宏` → `JS 宏编辑器`，版本不同入口略有差异）
3. 在编辑器中右键 → `插入模块`（或新建模块）
4. 把对应 `.js` 文件的全部内容粘贴进去
5. 选中目标单元格区域后，在宏编辑器里运行对应函数（或绑定到自定义按钮）

## 宏清单

| 文件 | 函数 | 功能 |
|---|---|---|
| 01_清除换行符.js | `SelectionClearLineBreaks` | 清除选区内所有手动换行符 |
| 02_不规则日期转标准日期.js | `NormalizeDates` | 各类手写日期 → 标准可计算日期 |
| 03_身份证信息提取.js | `ExtractIDInfo` | 识别身份证号，输出出生日期/性别/年龄 |
| 04_数据脱敏.js | `MaskSelection` | 手机号/身份证/姓名批量脱敏 |
| 05_取消公式保留值.js | `KeepValuesOnly` | 公式批量转静态值（覆盖前会确认） |
| 06_提取唯一值.js | `ExtractUniqueValues` | 提取不重复值写入右侧列 |
| 07_两区域差异对比.js | `CompareTwoRanges` | Ctrl 双选区逐格对比，差异标色 |

## 注意事项

- 宏一旦执行**不可撤销**（WPS 宏操作不进撤销栈），重要文件先备份
- 05 号宏执行前有确认弹窗；其余宏建议也在副本上先试运行
- 涉及个人隐私数据的宏（03/04）仅在本机运行，不经过任何网络
